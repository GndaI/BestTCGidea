# 최고의TCGidea(가제)

Godot 기반 CCG.
12장으로 구성된 덱을 선택해 6턴까지 매 턴 마다 낼 카드를 선택하며 전투 하는 게임이다.
하스스톤과 비슷하게 필드에 생명력이 있는 유닛들을 내지만, 공격력이 없고 생산력과 각 카드에 마나가 부여되는 것이 특징이다.

## 게임 하는 법 - Windows 기준

Godot에서 이 폴더의 `project.godot`을 연 뒤 `프로젝트 > 내보내기`에서 `Windows Desktop`을 선택해 내보냅니다. 기본 결과는 바탕 화면의 `최고의TCGidea.exe`이며 게임 데이터는 실행 파일 안에 포함됩니다.

친구에게 배포할 때에는 실행 파일을 ZIP으로 묶어 GitHub의 Releases에 올립니다. `build/`는 자동 생성 결과이므로 Git 저장소에는 포함하지 않습니다. 실행판의 온라인 화면에서는 서버 주소를 입력할 수 있으며, 입력한 주소는 해당 컴퓨터에 저장됩니다.

## 온라인 대전

Windows 실행판은 `https://besttcgidea-render-server.onrender.com`을 기본 온라인 서버로 사용합니다. 실행 후 `대전 → 온라인`으로 들어가면 주소 입력 없이 공개 방 목록을 불러옵니다.

한 명은 공개 방을 만들고 다른 한 명은 목록에서 그 방을 눌러 참가합니다. 참가자가 `준비`를 누르면 방장이 `덱 구성 시작`을 누릅니다.

Render 서버는 플레이어 컴퓨터와 별도로 실행되므로 다른 와이파이에서도 별도의 서버 실행이나 포트포워딩이 필요 없습니다. 무료 서버가 15분 동안 사용되지 않아 쉬는 중이면 첫 온라인 화면에서 다시 깨어날 때까지 최대 약 1분 걸릴 수 있으며, 방 목록은 10초마다 자동으로 다시 요청합니다.

온라인 화면에는 공개 방 목록과 방 만들기 영역만 표시됩니다. 다른 플레이어는 목록의 방을 눌러 바로 참가하며, 목록은 온라인 화면에 머무는 동안 10초마다 자동 갱신됩니다. 인원이 찬 방과 게임을 시작한 방은 `진행 중`으로 표시되어 입장할 수 없습니다.

## 코드 구조

```text
src/       게임 코드, 장면과 실제 사용 에셋
tests/     규칙·UI·AI·온라인 자동 검사
server/    Render 및 로컬 멀티플레이 중계 서버
docs/      현행 규칙, 카드 양식과 실행 안내
archive/   현재 게임에서 사용하지 않는 과거 자료와 원본
build/     내보낸 실행판과 웹판(자동 생성, Git 제외)
```

`src/` 안에서는 담당 기능을 기준으로 나눕니다.

- `scenes/`: 시작 장면과 장면에 연결된 중심 코드
- `battle/`: 카드 종류와 관계없는 전투 규칙
- `cards/`: 카드 목록과 카드별 효과 코드
- `ui/`: 화면과 재사용 UI 구성 요소
- `effects/`: 시각·소리·갬블 전용 연출 코드
- `ai/`: 쉬움·강함 AI 판단
- `online/`: 방 연결, 클라우드 덱과 계정
- `assets/`: 카드·UI 그림, 글꼴, 아이콘과 향후 추가할 소리 파일

문서 위치와 보관 기준은 [docs/README.md](docs/README.md)와 [archive/README.md](archive/README.md)를 참고합니다.

검사:
```powershell
godot --headless --path . --script res://tests/rules/test_rulebook.gd
godot --headless --path . --script res://tests/ui/test_rulebook_ui.gd
```

test_rulebook은 개별 효과와 일반 덱 자동 대전을 검사합니다.
