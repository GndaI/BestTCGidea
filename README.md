# 최고의 TCG IDEA — TWELVE

Godot 4.7 카드 전투 게임. **Windows 실행판을 기본 배포판**으로 사용하며, 같은 원본에서 웹판도 보조로 만들 수 있습니다.

## Windows 실행판 만들기 — 기본

Godot에서 이 폴더의 `project.godot`을 연 뒤 `프로젝트 > 내보내기`에서 `Windows Desktop`을 선택해 내보냅니다. 기본 결과는 `build/windows/TWELVE.exe`이며 게임 데이터는 실행 파일 안에 포함됩니다.

친구에게 배포할 때에는 실행 파일을 ZIP으로 묶어 GitHub의 Releases에 올립니다. `build/`는 자동 생성 결과이므로 Git 저장소에는 포함하지 않습니다. 실행판의 온라인 화면에서는 서버 주소를 입력할 수 있으며, 입력한 주소는 해당 컴퓨터에 저장됩니다.

웹판이 필요하면 같은 내보내기 화면에서 `Web`을 선택합니다. 웹판은 보조 배포판이며 원본 코드는 Windows판과 같습니다.

## 실행과 조작

project.godot을 Godot으로 열고 F5를 누릅니다. PvE는 기존 랜덤 AI(쉬움)와 필드 장악 AI(강함) 중 선택할 수 있습니다.
기존 카드 프레임, 마우스 확대, 주문 설명, 드래그 공격, 화살표, 피해·회복 연출을 유지했습니다.

- 각 단계의 카드 중 두 장을 선택해 12장 덱을 구성합니다.
- 쉬움 AI는 기존처럼 합법 행동 중 무작위로 선택합니다. 강함 AI는 상대 유닛의 확정 처치와 아군 생존을 우선하고, 생산력·마나·부활·보호 유닛의 위협도를 함께 평가합니다. 처치로 이어지지 않는 기본 공격과 일회용 피해 주문은 보류하며, 약한 유닛의 과잉 처치보다 위협적인 유닛을 효율적으로 제거합니다.
- 덱 구성 후보와 하단 완성 덱의 카드에 커서를 올리면 확대 카드와 효과 설명이 표시됩니다. 선택 카드는 녹색 배경/테두리, 체크 보석, ‘덱에 포함’ 표시로 구분됩니다.
- 덱 구성 맨 아래의 ‘완성 덱’에서 단계별 두 장씩 선택한 전체 덱과 장수를 확인할 수 있습니다.
- 자기 턴의 빈 체인에서 마나가 있는 아군 카드를 적에게 드래그하면 기본 공격입니다.
- 아군 카드를 짧게 누르면 소모 효과, 주문 패를 누르면 주문 대상 선택입니다. 기본 공격 드래그와 수습생의 주문/대상 선택을 포함한 모든 대상 지정은 우클릭으로 취소합니다.
- 피해/처치 직후 조건부 주문을 쓸 수 있을 때 잠시 멈춥니다. 패에서 해당 주문을 선택하거나 오른쪽 버튼으로 패스합니다.
- 불사조 주문은 처치된 아군 뒷면 카드를 대상으로 선택합니다. 재기불능 카드도 커서를 올리면 원래 카드와 효과를 확인할 수 있습니다.
- 성장 선택과 악마의 주사위 대상 선택은 기존 선택창과 같은 방식입니다.
- Esc 메뉴에서 ‘행동 없으면 자동 넘김’을 설정할 수 있습니다. 연출과 선택 중에는 자동 진행하지 않습니다.
- 턴이 바뀌면 중앙 표지에 전체 행동 턴과 다음 플레이어의 차례가 표시됩니다. 플레이 중에는 상단 상태표와 은은하게 빛나는 보드로 현재 턴 플레이어를 확인할 수 있습니다.
- 카드의 생산력은 왼쪽 아래, 생명력은 오른쪽 아래, 보유 마나는 위쪽입니다. 방어막은 푸른 테두리와 감소량으로 표시합니다.
- 사용된 주문은 P1/P2로 나뉜 하나의 기록 구역에 모이며 카드와 효과 문구를 계속 확인할 수 있습니다.
- 평상시 필드는 기존 여백과 6칸 구성을 유지합니다. 갬블의 악마는 P1 기준 보드 아래 중앙 제단에 등장하며, 상대 악마는 상대 보드 위쪽에 표시합니다.
- 악마가 등장하면 화면에 있던 실제 6칸 각각에 금이 번지고 깨진 뒤 빛기둥·회전 문양·충격파가 겹치는 상급 소환 연출이 나옵니다. 턴 종료 주사위는 1~6 룰렛으로 돌고, 멈춘 숫자와 효과 이름을 보여준 후 실제 효과를 적용합니다.
- 악마 룰렛 5번의 피해 대상은 목록이 아니라 중앙 제단의 악마를 필드 카드로 드래그해 지정합니다.
- 파괴 후 악마의 판은 높이가 불규칙한 9칸이 가로 광선으로 연결된 형태가 됩니다. 소환수는 빈칸부터 채우며, 9칸이 모두 차면 더 소환할 수 없습니다.
- 연출 중에는 입력/AI/자동 넘김이 기다립니다. 추가 주사위도 하나씩 룰렛과 효과를 순서대로 적용하며, 소환 하수인은 차례로 나타납니다.
- 초상화는 기존 assets/cards/<카드 ID>.png 또는 .jpg를 사용합니다. 새 카드용 그림이 없으면 기존 프레임만 표시합니다.

## 반영된 규칙

최신 문서와 대화의 확정 내용을 반영한 자세한 규칙은 [RULEBOOK.md](RULEBOOK.md)에 있습니다.
게임 안 ‘규칙’에서도 같은 내용을 볼 수 있습니다.

- 모든 소모 효과: 유닛당 한 턴에 한 번.
- 체인 대응: 소모 효과/주문만 가능.
- 턴 순서: 선1-후1-후2-선2-선3-후3-후4-선4-선5-후5-후6-선6-후7-선7…
- 6턴 이후 서로 한 턴씩 교대.
- 시간여행자: 4단계를 건너뛰고 다음 자신의 턴에 5단계 공개.
- 부활: 자신의 턴으로 계산, 초기 상태로 복귀, 부활 예정이어도 전멸 시 패배.
- 수습생: 조건부 주문 복사 금지, 주문 복사 원본은 아군만.
- 배신자: 살아 있는 상대 5단계와 소유권 교환, 남은 마나 유지.

## 현재 보충 규칙

시간여행자의 주마등에는 현재 별도 효과가 없습니다.
악마 4번은 상대의 사용된 주문 중 현재 적용 가능한 하나를 고르며, 악마 주문은 룰렛을 한 번 굴립니다. 조건이 맞지 않는 결과는 꽝입니다.
방어막은 합산되어 중첩되고 턴 종료에 사라집니다. 바위 골렘이 방어막으로 막으면 방어막은 1만 감소합니다.
생명력 부여는 현재·최대 생명력을 함께 올리고, 생명력을 가져오면 대상의 현재·최대 생명력이 함께 감소하며 불사조의 두 수치가 함께 증가합니다.
가시 골렘의 반사는 기본 공격과 소모 효과 피해에만 발동합니다.
악마의 중앙 제단을 제외한 놀이판에는 카드를 최대 9장까지 놓을 수 있습니다.

## 온라인 1대1

Windows 실행판과 웹판은 같은 온라인 방 서버를 사용합니다. Windows판에서는 온라인 화면 위쪽의 서버 주소에 `http://127.0.0.1:8000` 또는 전달받은 `https://...trycloudflare.com` 주소를 입력하고 `적용`을 누릅니다. 웹판은 현재 접속한 게임 주소를 자동으로 사용합니다.

`서버-열기.bat`를 실행한 뒤 각자 Windows 게임의 온라인 화면에서 서버 주소를 적용합니다. 한 명은 공개 방을 만들거나 비공개 방 코드를 전달하고, 다른 한 명은 목록에서 방을 누르거나 코드를 입력해 참가합니다. 두 명이 연결되면 방장이 `덱 구성 시작`을 누릅니다.

같은 컴퓨터에서는 `http://127.0.0.1:8000`, 같은 와이파이의 다른 Windows 기기에서는 서버 컴퓨터의 사설 IP 주소와 8000번 포트를 사용합니다. 현재 구조는 방장이 전투 판정을 맡고 중앙 WebSocket 서버가 두 게임 사이의 덱·행동·전투 상태 메시지를 전달합니다. 플레이어끼리 직접 연결하지 않으므로 별도의 WebRTC 확장이나 TURN 서버는 필요하지 않습니다.

다른 와이파이의 친구와 시험할 때에는 `인터넷-서버-열기.bat`를 실행합니다. 계정이나 포트포워딩 없이 임시 `https://...trycloudflare.com` 주소가 발급되며 `public-address.txt`에도 저장됩니다. 두 사람 모두 Windows 게임의 서버 주소 칸에 이 주소를 입력합니다. 주소는 서버를 다시 실행할 때마다 바뀌고, 주소를 아는 사람은 접속할 수 있으므로 테스트할 친구에게만 전달합니다.

온라인 화면 위쪽에는 공개 방 목록이 표시됩니다. 방 이름을 입력해 공개 방을 만들 수 있고, 다른 플레이어는 목록의 방을 눌러 바로 참가합니다. 목록은 온라인 화면에 머무는 동안 10초마다 자동 갱신됩니다. 인원이 찬 방과 게임을 시작한 방은 `진행 중`으로 표시되어 입장할 수 없습니다. 기존 여섯 자리 방 코드 방식은 같은 화면 아래쪽의 `비공개 방` 영역에 유지됩니다.

## 코드와 검증

- cards.gd: 카드 목록과 조회
- card_effects/<id>.gd: 개별 카드 수치·텍스트
- card_effects/rulebook_effect.gd: 공통 카드 훅
- battle.gd: 전투·체인·부활·주사위 처리
- random_ai.gd: 합법 행동과 랜덤 AI
- field_ai.gd: 필드 유닛 수 우위를 목표로 하는 강함 AI
- main.gd / card_view.gd: 기존 UI, 입력, 온라인 동기화

검사:
```powershell
godot --headless --path . --script res://tests/test_rulebook.gd
godot --headless --path . --script res://tests/test_rulebook_ui.gd
godot --headless --path . --script res://tests/test_deck_gamble_ui.gd
```

test_rulebook은 개별 효과와 일반 덱 자동 대전을 검사합니다. 무제한 소환 때문에 악마는 개별 주사위 효과로 검사하며 일반 덱의 종료 검사에서는 제외합니다.
test_deck_gamble_ui는 덱 설명 유지/선택 표시/완성 덱 갱신, 악마 중앙 배치, 룰렛 결과와 적용 시점, 소환 위치와 가로 확장/스크롤 유지, 연출 중 자동 행동 정지와 온라인 룰렛 상태 전달을 검사합니다.
기존 test_battle/test_spells_ai/test_effects 등의 일부 기대값은 구버전 카드 기준이므로 최신 규칙 검증에는 위 검사를 사용합니다.
