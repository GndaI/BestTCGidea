# 소스 코드

- `scenes/`: 게임의 시작점과 전체 장면 전환
- `core/`: 카드 종류와 관계없는 전투 진행 규칙
- `cards/`: 카드 목록과 카드별 효과 코드
- `ui/components/`: 여러 화면에서 재사용하는 UI 노드
- `ui/screens/`: 화면별 장면, 화면 코드와 표시 데이터
- `effects/visual/`: 일반 전투 시각 연출
- `effects/gamble/`: 갬블의 악마 전용 연출
- `effects/sound/`: 소리 연출
- `ai/`: 컴퓨터 상대의 행동 판단
- `online/`: 계정, 클라우드 덱과 온라인 방 연결
- `assets/`: 카드·UI 그림, 글꼴, 아이콘과 앞으로 추가할 소리 파일

이미지·소리·글꼴·아이콘은 `assets/`에, 게임을 작동시키는 코드와 장면은 담당 기능 폴더에 둡니다.

새 화면은 `.tscn`과 연결된 `.gd`를 `ui/screens/<화면 이름>/`에 함께 둡니다. 카드처럼 여러 화면에서 반복 사용하는 시각 요소는 `ui/components/`에 둡니다. 전투 규칙, 카드 데이터와 AI처럼 화면에 직접 배치되지 않는 코드는 씬으로 만들지 않습니다.
