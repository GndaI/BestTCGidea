# 에셋

게임에서 표시하거나 재생하는 원본 재료를 모아 둡니다.

- `cards/`: 카드 그림
- `ui/`: 화면 배경과 UI 그림
- `fonts/`: 글꼴과 라이선스
- `icons/`: 게임 아이콘

앞으로 시각 효과용 그림은 `effects/visual/`, 효과음과 음악은 `effects/sound/` 하위 폴더를 만들어 보관합니다. 이 폴더에는 게임 동작을 구현하는 `.gd` 코드나 `.tscn` 장면을 넣지 않습니다.

실제 게임에서 읽지 않는 제작 원본과 이전 버전 이미지는 `archive/assets/`에 보관합니다.
