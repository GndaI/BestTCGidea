# 웹 전환 계획

> 과거 웹 중심 개발 방향을 보관한 문서입니다. 현재 배포 기준은 루트 `README.md`를 따릅니다.

## 보존 원칙

- 실제 친구 대전이 완료된 `최고의-tcg-idea (2)`는 수정하지 않는다.
- 웹 관련 변경은 이 `최고의-tcg-idea-web` 폴더에서만 진행한다.
- 전투 규칙, 카드 효과, 체인과 화면 구성은 가능한 한 그대로 재사용한다.

## 현재 단계

- Godot Web 내보내기 프리셋을 추가했다.
- Godot 4.7.2 웹 내보내기 템플릿을 설치하고 `build/web/index.html` 생성을 확인했다.
- Windows 실행판과 웹판이 함께 사용할 수 있는 중앙 WebSocket 중계 연결로 교체했다.
- `서버-열기.bat` 하나가 웹 게임과 방 코드 중계를 함께 제공한다.
- 방 만들기, 여섯 자리 코드 참가, P1·P2 배정과 덱 구성 시작 동기화를 실제 브라우저 두 개로 확인했다.
- `인터넷-서버-열기.bat`로 계정이나 포트포워딩 없이 임시 HTTPS 공개 주소를 만들 수 있다.
- 공개 주소에서 HTTPS 페이지와 WSS 방 생성·참가 메시지 전달을 확인했다.
- 온라인 화면에 공개 방 목록과 이름 있는 방 만들기를 추가했다. 목록은 10초마다 자동 갱신되며 버튼으로 바로 참가한다.
- 기존 여섯 자리 비공개 방은 공개 목록 아래에 유지했다.
- Windows 클라이언트 두 개로 방 생성, 참가, 대기방, 덱 제출, 전투 상태 동기화를 확인했다.

## 다음 단계

1. 서로 다른 실제 기기에서 한 판을 끝까지 검증한다.
2. 임시 공개 주소를 24시간 고정 서버 주소로 옮긴다.
3. 호스트 플레이어에게 묶인 판정을 별도 권위 서버로 옮길지 결정한다.
4. 끊김, 재접속, 서로 다른 버전 접속을 처리한다.

## 목표 접속 흐름

`Windows 게임 실행 → 서버 주소 적용 → 방 만들기 → 친구가 방 목록에서 참가 → 대전`
