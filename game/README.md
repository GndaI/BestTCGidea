# 게임 본체

- `scenes/`: 시작 장면과 장면에 연결된 중심 코드
- `core/`: 카드 종류와 관계없는 전투 진행 규칙
- `cards/`: 카드 목록, 카드별 효과와 카드 그림
- `ui/`: 화면 구성 요소, 화면별 코드와 UI 이미지
- `effects/visual/`: 일반 전투 시각 연출
- `effects/gamble/`: 갬블의 악마 전용 연출
- `effects/sound/`: 소리 연출
- `ai/`: 컴퓨터 상대의 행동 판단
- `online/`: 계정, 클라우드 덱과 온라인 방 연결
- `shared/`: 여러 기능에서 공통으로 쓰는 글꼴과 아이콘

새 파일은 확장자보다 담당 기능을 기준으로 가장 가까운 폴더에 둡니다.
