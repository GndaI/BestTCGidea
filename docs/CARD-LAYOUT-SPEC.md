# 유닛 카드 공용 배치 규격

이 문서는 여러 유닛 카드가 같은 외곽, 게이지, 수치 위치를 공유하기 위한 시각 규격이다.

현재 상태는 `0.1-draft`이다. 와이어프레임에서 위치를 더 조정하면 문서와 [`specs/card-layout-spec.json`](specs/card-layout-spec.json)을 함께 갱신한다. 실제 Godot 카드 UI는 사용자가 이 규격을 확정한 뒤 변경한다.

## 기본 좌표계

- 기준 크기: `280 × 280 px`
- 원점: 카드 바깥 사각형의 왼쪽 위 `(0, 0)`
- 모든 좌표는 기준 크기에서 기록한다.
- 다른 크기로 표시할 때에는 `표시 크기 / 280`의 단일 배율을 위치, 크기, 글자, 선 굵기에 함께 적용한다.
- 가로와 세로를 서로 다른 비율로 늘리지 않는다. 남는 공간이 있으면 카드 바깥에 둔다.
- 카드 안의 값이나 문구가 바뀌어도 외곽 크기와 슬롯 크기는 변하지 않는다.

## 고정 형상

### 외곽 꼭짓점

| 지점 | 좌표 |
|---|---:|
| O0 | `(140, 0)` |
| O1 | `(280, 84)` |
| O2 | `(227, 280)` |
| O3 | `(53, 280)` |
| O4 | `(0, 84)` |

### 그림 영역 꼭짓점

| 지점 | 좌표 |
|---|---:|
| I0 | `(140, 47.5)` |
| I1 | `(231.4, 116.9)` |
| I2 | `(194.4, 241.9)` |
| I3 | `(85.6, 241.9)` |
| I4 | `(48.6, 116.9)` |

### 꼭짓점과 선

- O0와 I0은 뾰족한 꼭짓점으로 유지한다. 둥근 꼭짓점으로 바꾸지 않는다.
- 게이지 두께는 이전 100% 형상의 `85%`를 기준으로 한다. 현재 70% 형상과 이전 100% 형상의 내부점을 정확히 절반 보간한 좌표이다.
- 나머지 외곽 꼭짓점의 기본 곡률 반경은 `8 px`이다.
- 나머지 내부 꼭짓점의 기본 곡률 반경은 `7 px`이다.
- 외곽선, 내부선, 생산력 분리선의 기준 굵기는 모두 `3 px`이다.
- 내부 그림 영역은 내부 꼭짓점으로 만든 경로에 맞춰 자른다.
- 장식은 이 형상 바깥의 별도 층으로 추가하며, 기준 좌표나 카드 크기를 바꾸지 않는다.

## 영역

| 영역 | 경계 | 역할 |
|---|---|---|
| 마나 | `O0 → O4 → O3 → I3 → I4 → I0` | 왼쪽 파란 게이지 |
| 체력 | `O0 → O1 → O2 → I2 → I1 → I0` | 오른쪽 빨간 게이지 |
| 생산력 | `O3 → O2 → I2 → I3` | 아래 노란 고정 영역 |
| 그림 | `I0 → I1 → I2 → I3 → I4` | 카드별 일러스트 |

- 마나와 체력의 연한색은 비어 있는 양, 진한색은 현재 양이다.
- 생산력은 채움 게이지가 아니라 항상 같은 크기의 고정 영역이다.
- 값의 변화는 색 면과 숫자만 갱신한다. 영역의 경계와 카드 크기는 갱신하지 않는다.

## 수치 위치

수치는 아래 중심점에 고정하고 가로·세로 중앙 정렬한다.

| 수치 | 중심점 | 기준 상자 | 정렬 |
|---|---:|---:|---|
| 마나 | `(55, 220)` | `48 × 36 px` | 상하·좌우 중앙 |
| 체력 | `(225, 220)` | `48 × 36 px` | 상하·좌우 중앙 |
| 생산력 | `(140, 261)` | `44 × 32 px` | 상하·좌우 중앙 |

- 기준 글자 크기는 `18 px Bold`이다.
- 한 자리와 두 자리 숫자는 같은 중심점을 사용한다.
- 수치 변화, 강조, 깜빡임 중에도 위치와 상자 크기는 바뀌지 않는다.
- 숫자의 외곽선이나 그림자는 글자 바깥에 그리며 수치 상자의 배치에는 포함하지 않는다.

## 게이지 진행

### 마나

- 시작점은 왼쪽 아래 생산력 경계, 끝점은 O0의 궁극기 발동점이다.
- 현재 마나 비율은 `현재 마나 / 최대 마나`이다.
- 최대 마나는 해당 카드의 궁극기 소모량으로 정한다.
- 스킬 소모량은 중복을 제거하고 작은 값부터 정렬해 눈금으로 표시한다.
- 궁극기 소모량은 O0 자체가 끝점이므로 별도 눈금을 겹쳐 그리지 않는다.
- 최대 마나가 `0`인 카드는 진한 채움을 표시하지 않고 소모 눈금도 만들지 않는다.

### 체력

- 최대 체력일 때 진한 빨강이 체력 게이지 전체를 채운다.
- 피해를 받으면 O0 쪽부터 진한 영역이 줄어든다.
- 현재 체력 비율은 `현재 체력 / 최대 체력`이다.
- `5, 10, 15…` 중 최대 체력보다 작은 값마다 눈금을 표시한다.

### 현재값 경계선

- 진한색과 연한색이 만나는 위치에 `2 px`의 어두운 경계선을 둔다.
- 경계선은 해당 지점의 바깥 테두리부터 안쪽 테두리까지 끊김 없이 곧게 연결한다.
- 경계선은 게이지 진행 방향과 직각이다.

## 눈금 규칙

- 눈금의 기준 굵기는 `3 px`이다.
- 눈금은 어둡고 선명하게 표시한다.
- 눈금은 바깥 테두리에서 시작한다.
- 눈금은 그 지점의 바깥 테두리와 직각이다.
- 그 지점에서 바깥 테두리와 안쪽 테두리 사이의 거리를 `W`라고 하면 눈금 길이는 정확히 `W / 3`이다.
- 눈금 끝점은 아래 식으로 계산한다.

```text
끝점 = 바깥점 + 안쪽 방향 단위 법선 × (W / 3)
```

- 임의의 화면 좌표 두 개를 저장해 눈금을 그리지 않는다. 게이지 형상이 바뀌면 법선과 교점을 다시 계산한다.

## 카드마다 바뀌는 값

공용 틀은 아래 데이터만 받아서 표시한다.

| 데이터 | 사용처 |
|---|---|
| `portrait` | 내부 그림 영역 |
| `production` | 생산력 숫자 |
| `health`, `max_health` | 체력 숫자와 채움 비율 |
| `mana`, `max_mana` | 마나 숫자와 채움 비율 |
| `ability_costs` | 마나 소모 눈금 |
| `highlight_state` | 선택 가능, 대상, 사용 가능 등의 별도 강조층 |

카드 이름, 효과 설명, 턴 표시는 이 필드용 몸체 안에 넣지 않는다. 필요한 화면에서는 카드 바깥의 공용 오버레이나 호버 정보로 표시한다.

## 층 순서

아래에서 위 순서로 그린다.

1. 카드별 그림
2. 마나·체력의 연한 바탕
3. 마나·체력의 현재값 채움
4. 생산력 고정 영역
5. 현재값 경계선과 눈금
6. 외곽선·내부선·분리선
7. 마나·체력·생산력 숫자
8. 선택·대상·사용 가능·피해 예상 등의 상태 강조
9. 장식

상태 강조와 장식은 숫자 위치, 게이지 경계, 카드의 실제 클릭 영역을 바꾸지 않는다.

## 표시 크기 변환

```text
scale = target_size / 280
화면 좌표 = 기준 좌표 × scale
화면 선 굵기 = 기준 선 굵기 × scale
화면 글자 크기 = 기준 글자 크기 × scale
```

- 필드, 덱 제작, 덱 선택, 호버 확대는 같은 기준 좌표를 사용한다.
- 화면별 차이는 카드 전체에 적용하는 단일 배율뿐이다.
- 최소 선 굵기나 최소 글자 크기 때문에 보정이 필요하면 마지막 렌더 단계에서만 보정하고, 기준 좌표는 바꾸지 않는다.

## 구현 전 확인

- 현재 편집판에서 외곽·내부 꼭짓점과 세 숫자 중심점을 최종 확인한다.
- 두 자리 체력 `19`, 두 자리 마나, 한 자리 생산력을 넣어도 중앙 정렬되는지 확인한다.
- 서로 다른 소모량 목록을 가진 카드 세 장 이상으로 마나 눈금을 확인한다.
- 최대 체력 `3`, `12`, `19`로 체력 눈금과 채움 방향을 확인한다.
- Godot UI 구현은 이 확인을 마친 뒤 시작한다.
