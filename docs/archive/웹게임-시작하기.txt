[보관 문서] 과거 Windows 멀티와 웹게임 시작 방법

현재는 Render 고정 서버를 사용합니다. 최신 사용법은 docs/setup/윈도우-멀티-시작하기.txt를 확인합니다.

다른 와이파이 또는 다른 장소의 친구와 하기

1. 인터넷-서버-열기.bat를 두 번 클릭합니다.
2. 잠시 기다리면 검은 창에 https://로 시작하는 PUBLIC GAME ADDRESS가 표시됩니다.
3. 두 사람 모두 Windows 게임의 온라인 화면에서 그 주소를 입력하고 '적용'을 누릅니다.
4. 공개 방을 만들면 친구는 목록에서 방을 눌러 들어갑니다. 비공개 방이라면 여섯 자리 코드를 친구에게 보냅니다.
5. 게임하는 동안 검은 창을 닫지 않습니다.
6. 서버를 다시 켜면 공개 주소가 바뀌므로 새 주소를 다시 보내야 합니다.

같은 컴퓨터 또는 같은 와이파이에서만 하기

1. 서버-열기.bat를 두 번 클릭합니다.
2. 서버 컴퓨터의 Windows 게임에는 http://127.0.0.1:8000 을 입력하고 적용합니다.
3. 같은 와이파이의 다른 Windows 게임에는 http://192.168.0.120:8000 을 입력하고 적용합니다.
4. 첫 번째 사람은 공개 방을 만들거나 비공개 방을 만듭니다.
5. 두 번째 사람은 공개 방 목록에서 누르거나 여섯 자리 코드를 입력해 참가합니다.
6. 두 명이 연결되면 방장이 '덱 구성 시작'을 누릅니다.

서버를 끄려면 서버 창을 닫습니다.

주의
- 192.168.0.120은 현재 이 컴퓨터의 와이파이 주소입니다. 공유기나 네트워크가 바뀌면 주소도 바뀔 수 있습니다.
- Windows 방화벽 질문이 나오면 같은 와이파이에서 시험할 때 '개인 네트워크'만 허용합니다.
- 인터넷 공개 주소는 시험용 임시 주소입니다. 주소를 아는 사람은 접속할 수 있으므로 모르는 사람에게 공개하지 않습니다.
- 전투 데이터는 중앙 서버가 전달하므로 플레이어끼리 직접 연결하거나 포트포워딩할 필요가 없습니다.
