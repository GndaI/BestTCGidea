# 운명 템플릿

운명 덱은 12장이고 같은 운명은 최대 2장까지 넣는다. 게임 시작 시 양쪽 플레이어가 섞인 운명 덱에서 2장씩 뽑고, 첫 턴을 포함한 자신의 턴 시작마다 1장 더 뽑는다.

운명은 기본적으로 `유발`이다. 자신의 주요 시기이며 체인이 비어 있을 때 사용한다. 살아 있는 아군 유닛 하나가 비용 전부를 자신의 마나로 지불하며, 여러 유닛의 마나를 합칠 수 없다. 비용 0이어도 지불 유닛을 지정한다.

운명은 선언할 때 손에서 빠지고, 체인이 해결되면 사용된 운명 영역으로 간다. 운명 비용 지불은 지불 유닛의 소모 효과 사용 횟수를 쓰지 않는다.

아래 양식을 복사해 운명을 작성한다. 모든 운명의 사용 시기가 같으므로 카드마다 시기를 반복해서 적지 않는다.

```markdown
## [운명 이름]

비용: [마나]

**효과**

[효과 내용]
```

`비용을 지불한 유닛`을 대상으로 하는 효과라면 효과 문장에 직접 명시한다.
