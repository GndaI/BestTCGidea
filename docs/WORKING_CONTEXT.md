# 현재 작업 맥락

이 문서는 여러 작업 대화가 함께 확인하는 임시 인수인계 문서입니다. 확정된 내용은 담당 기준 문서로 옮기고 여기에서는 제거합니다.

## 진행 중

- [16:9 화면 전환] 내부 기준 해상도 `1600×900`, 기본 실행 창 `1280×720`을 최종 유지할지 결정해야 합니다. 실제 1280×720 전투 캡처에서는 스크롤이나 잘림 없이 필드·주문 영역·행동 버튼이 표시되었습니다.
- [대전 레이아웃] 대응 단계의 `피해/처치 직후` 안내를 전투 레이아웃의 행에서 제거하고, 보드를 밀지 않는 화면 오버레이로 옮겼습니다.
- [게임 모드 기반] 현재 선택지는 기존 규칙을 뜻하는 `기본 모드` 하나입니다. AI와 로컬은 공용 `GameModeSelectScreen`에서 모드를 고른 뒤 각각 AI 난이도와 P1 덱 선택으로 이동합니다. 온라인은 방 이름 아래에서 모드를 고르며, 방 목록·대기방·서버 방 정보와 참가자 동기화에 모드 ID를 포함합니다. 아직 커밋하거나 공개 서버에 배포하지 않았습니다.

## 임시 결정

- 카드 내부 UI는 구조와 문구가 더 바뀔 수 있으므로 계속 동적으로 생성합니다. 카드가 들어가는 슬롯과 카드 밖의 화면 틀은 재사용하는 방향을 유지합니다.
- 지금까지 만든 카드와 전투 규칙을 `기본 모드`의 기준으로 고정합니다. 실험 모드는 기본 규칙을 직접 바꾸지 않고, 카드·규칙 대화에서 목적과 변경 규칙을 먼저 정한 뒤 별도 모드로 추가합니다.
- 게임 모드 목록은 `src/battle/game_modes.gd`에서 공통 관리하고 AI·로컬·온라인이 같은 모드 ID와 이름을 사용합니다.
- AI는 자동 테스트까지만 실행하고, Godot 화면 배치와 실제 조작 확인은 사용자가 직접 합니다.

## 확인 필요

- [사용자 확인] Godot 디버그에서 덱 보관함, 덱 제작, 대전을 차례로 열어 클릭 전후 위치 유지와 중앙 경고 연출을 확인해야 합니다.
- [사용자 확인] 온라인 방 만들기 화면을 1280×720에서 열어 방 이름, 게임 모드, 설명과 방 만들기 버튼이 잘리지 않는지 확인해야 합니다.
- [사용자 확인] AI와 로컬에서 게임 모드 선택 화면의 배치와 다음·뒤로 이동을 확인해야 합니다.
- 자동 검사는 카드 자동 실패 0, 카드 재작업 39/39, 규칙 2727/2727, AI·로컬 6/6, 드래그 실패 0, UI 138/138, 부분 갱신 11/11을 통과했습니다. 로컬 방 서버의 Node 중계 검사와 Godot 방 중계·전체 온라인 대전 동기화 검사도 실패 0으로 통과했습니다.

## 다음 작업

- 사용자가 세 UI 화면의 위치 유지, 온라인 방 만들기의 모드 선택 배치, AI·로컬 공용 모드 선택 흐름을 직접 확인합니다.
- 16:9 화면 전환의 최종 유지 여부를 결정합니다.
- 카드·규칙 대화에서 첫 번째 실험 모드의 목적, 이름, 기본 모드와 달라지는 규칙, 덱 제한과 온라인 지원 여부를 먼저 정합니다.
- 규칙이 합의되면 `src/battle/game_modes.gd`에 모드를 등록하고 전투 규칙 설정을 연결합니다.
