# Windows 온라인 대전 시작하기

## 두 플레이어 공통

1. `최고의TCGidea.exe`를 실행하고 `대전 → 온라인`으로 들어갑니다.
2. 첫 접속에서 방 목록이 바로 나오지 않으면 무료 서버가 깨어날 때까지 최대 약 1분 기다립니다. 목록은 10초마다 자동으로 갱신됩니다.
3. 한 명이 방 이름을 적고 공개 방을 만듭니다.
4. 다른 한 명은 공개 방 목록에서 해당 방을 눌러 참가합니다.
5. 참가자가 `준비`를 누릅니다.
6. 두 명 모두 준비되면 방장이 덱 구성을 시작합니다.

기본 서버는 `https://besttcgidea-render-server.onrender.com`으로 설정되어 있습니다. 평소에는 별도의 서버 주소를 입력하거나 서버 프로그램을 실행할 필요가 없습니다.
